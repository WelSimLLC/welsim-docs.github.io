# Solvers

WELSIM supports multiple solvers, including *FrontISTR*, *Elmer FEM*, *OpenRadioss*, *CalculiX*, *SU2*, *Palace*, *MFEM*, *OpenFOAM* and *LAMMPS*. Among them, *FrontISTR*, *SU2*, and *Palace* are included in the installer. Other solvers such as *Elmer FEM*, *OpenRadioss*, *CalculiX*, and *LAMMPS* are not included in the installer due to GNU open-source license restrictions. Users need to download them independently and perform simple configurations through WELSIM's preferences.

For more relevant information, you can refer to the [external solvers](../external_solvers.md).

The installer also offers a **Scripting & AI (MCP)** component: the embedded Python runtime, the WELSIM engine with its `WsmCli` command-line host, and the MCP server used by AI agents. It is described in [Scripting and automation](../scripting.md).

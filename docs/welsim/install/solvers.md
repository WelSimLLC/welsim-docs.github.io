# Solvers

WELSIM supports multiple solvers, including *FrontISTR*, *Elmer FEM*, *OpenRadioss*, *CalculiX*, *SU2*, and *LAMMPS*. Among them, *FrontISTR*, *SU2*, and *Palace* are included in the installer. Other solvers such as *Elmer FEM*, *OpenRadioss*, *CalculiX*, and *LAMMPS* are not included in the installer due to GNU open-source license restrictions. Users need to download them independently and perform simple configurations through WELSIM's preferences.

For more relevant information, you can refer to the [external solvers](../external_solvers.md).
